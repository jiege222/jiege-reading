# 杰哥阅读：MVP 产品设计

## 产品方向

做一个轻量的本地 TXT 电子书阅读器，让用户完成“导入一本书 → 舒服地阅读 → 关闭后继续阅读”的完整流程。

面向主要阅读中文小说、文字类书籍的个人用户。第一版以基础阅读体验和稳定性为重点，先满足日常使用，再根据实际反馈迭代。

## 第一版形态

采用网页形式，适配电脑和手机浏览器。书籍、阅读位置和阅读设置保存在当前浏览器本地，无需登录和后端服务。

清除浏览器数据或更换设备后，本地书籍和进度不会自动保留；界面应提示用户保留原始 TXT 文件。

## 主要功能

| 功能 | MVP 范围 |
| --- | --- |
| 导入 TXT | 选择本地 TXT 文件；支持 UTF-8、GBK 编码，识别异常时允许手动切换；空文件、读取失败等情况给出明确提示 |
| 简单书架 | 以文件名作为书名，显示最近阅读时间，最近阅读的书排在前面；支持打开和删除，删除前确认 |
| 正文阅读 | 上下滚动阅读，正确显示中文、换行和段落；适配不同屏幕尺寸；长篇小说阅读保持流畅 |
| 阅读设置 | 调整字号和行距，切换浅色、深色主题；设置自动保存，并应用到后续阅读 |
| 自动续读 | 每本书独立保存阅读位置，重新打开自动恢复；调整字号、行距或窗口大小后，仍能定位到原来的正文附近 |
| 本地保存 | 导入成功后保存书籍内容，刷新页面或关闭后重新打开，无需重复导入；保存失败时提示用户 |

阅读位置按正文内容位置记录，不只依赖滚动像素值。长文件应采用适当的分段加载或渲染方式，避免一次性渲染全文造成明显卡顿。

## 页面与流程

- **书架页**：导入入口、书籍列表、打开和删除操作；没有书籍时提示导入第一本书。
- **阅读页**：书名、正文、返回书架入口、阅读设置；打开书籍时自动恢复上次阅读位置。

首次使用：打开书架 → 导入 TXT → 开始阅读 → 调整阅读设置 → 自动保存。

再次使用：打开书架 → 选择已导入的书籍 → 从上次位置继续阅读。

## 暂不包含

书签、章节识别与目录、封面、书内图片、EPUB/PDF 等其他格式，以及全文搜索、划线笔记、登录注册、云端同步、AI 功能、语音朗读和翻页动画，均留待后续迭代。

后续功能按实际阅读反馈决定优先级，本版不提前建设对应系统。

## 交付验收

1. UTF-8 和 GBK 的中文 TXT 均能正常导入，正文不乱码；手动切换编码有效。
2. 导入长篇小说后，打开、滚动阅读和调整设置没有明显卡顿。
3. 字号、行距和主题设置生效，刷新后仍保留。
4. 多本书的进度互不影响；刷新、关闭后重新打开，以及调整排版后，均能恢复到原来的正文附近。
5. 电脑和手机上正文不横向溢出，基本操作可用。
6. 空文件、非 TXT 文件、读取或保存失败时有清晰提示；删除一本书后，其内容和进度被清理，其他书籍不受影响。

实现过程中为相应功能编写或更新测试，交付前确保全部测试和验证通过，并为每次改动创建 Git commit。
